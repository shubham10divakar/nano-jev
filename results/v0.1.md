# Nano-Jev v0.1 results (2026-09-25)

**Model:** `cross-encoder/ms-marco-MiniLM-L6-v2` (~22M params), fine-tuned 2 epochs,
batch 16 examples, lr 3e-5, max length 512, bf16 on an RTX 3060.
**Data:** `prepare_data.py --preset default` (seed 0) — 49,760 train examples from
HotpotQA distractor (6k questions), SQuAD 2.0 (6k), MultiNLI (8k).
**Training time:** ~7 min/epoch (6,220 steps total). Dev NLL 0.928 → 0.491.

Test split = held-out halves of the validation sets. Temperatures fitted on the calib halves.
Accuracy / F1 are after calibration (temperature scaling doesn't change argmax).

## Notes

- The trained model is slightly **overconfident** (all T > 1); temperature scaling cuts
  ECE to ~0.02 on relevance and sufficiency.
- ms/decision is batched GPU throughput (batch 32), not single-request latency.
- "partially relevant" is the weakest class (macro-F1 < accuracy on relevance).
- The baseline is only the untrained init. Still to add: bge-reranker-v2-m3 (relevance)
  and prompted Qwen3-4B via Ollama (all three).
- Dynamic options work mechanically (demo: an unseen "topic" choice ranks the right
  label first), but the model was never trained on open-ended choices, so those
  probabilities are weak.
